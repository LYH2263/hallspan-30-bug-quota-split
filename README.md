# HallSpan 考场间距排座

在考室网格上按最小曼哈顿距离排座，同试卷套不得四邻相邻，并输出违规与统计。

## 前排名额台账

系统维护的是「前排名额台账 + 座位方案」联动，而不是「有标记就必须坐前排」的单条规则：

- 名额格数（前排行数 × 列数）只在点排座提交的瞬间重算并写入台账，不沿用上次缓存。
- 特殊考生先排且只能消耗名额格；普通人禁止占用名额格，前排空着也不用普通人凑满。
- 排座图、名额已耗、统计前排占用同源于一次计算，交叉校验通过才落库；对不齐整场失败且不新增方案。
- 名额不足（或前排几何放不下）时直接拒绝，不允许「先排普通人再把特殊考生丢进未排」。
- 改前排行数或改标记在同一事务内完成：行数/标记、台账、最新方案同成功或同失败。
- 历史方案的名额数字钉死在生成当时，后续改动不回刷。
- 前排行数为 0 表示关闭名额账、退回现网；为负或超过考室行数则拒绝保存。

技术栈：Python 3.12 / FastAPI / SQLAlchemy / PostgreSQL / Vue 3 / TypeScript / Vite

## 启动

```bash
docker compose up --build
```

健康检查：`GET http://localhost:9900/api/health`

## 使用说明

1. 在「考室」设置前排行数（0 关闭名额账；负数或超过考室行数会被拒绝）。
2. 在「考生名册」用「标为特殊」维护特殊考生标记；名额不足时切换会被整体拒绝。
3. 打开「排座图」执行排座：前排名额区高亮，名额已耗/总额与图一致。
4. 在「违规」查看间距或同卷相邻问题。
5. 在「统计」查看占用、违规汇总与前排名额台账（前排占用＝名额已耗）。
